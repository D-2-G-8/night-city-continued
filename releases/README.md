# releases/

Signed release manifests (`X.Y.Z.json`) and their minisign signatures (`.minisig`).

These files are generated by `tools/release.ps1` and signed in the release CI environment.
**They are evidence, not source.** Never hand-edit one — agents are denied write access
here on purpose. To change what a release contains, cut a new release.

Alongside each manifest there may be `X.Y.Z.pins.json`, a signed addendum carrying **only**
upstream refs and hashes for `linked` recipes, plus a monotonic `revision` (ADR-009). It
exists so that a third-party author updating their own file does not force a new release.
The manifest itself stays immutable and its signature stays valid. An addendum containing
anything beyond refs and hashes is rejected by the launcher.
